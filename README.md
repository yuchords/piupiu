## 4. 硬件需求清单 (BOM 规划)
基于目前 piupiu 桌面终端的功能规划（HoloCubic 全息显示、LVGL UI、语音唤醒、网络通信、音频播放），以下是推荐的硬件选型方案：

### 4.1 核心主控 (MCU & 存储)
*   **主控芯片**: **ESP32-S3 (推荐 ESP32-S3-WROOM-1-N16R8)**
    *   **理由**: 必须具备强大的 AI 算力（用于 `esp-sr` 语音唤醒）和充足的内存（LVGL 渲染 + DataCenter 缓冲）。
    *   **要求**: 至少 8MB PSRAM (用于分配 LVGL 大图缓存和多 App 栈) + 16MB Flash (用于存储音频 UI 素材和固件)。
*   **下载与调试**: 推荐使用 CH343P 或 CP2102N 芯片，带自动下载电路（EN/BOOT）。

### 4.2 显示与交互 (Display & Input)
*   **全息棱镜屏幕**: **1.54 寸或 1.3 寸 高分屏 TFT/OLED (推荐 ST7701S 或 RM69330 驱动)**
    *   **分辨率**: 320x320 或 454x454，RGB 或 QSPI/MIPI 接口。
    *   **理由**: 相比 240x240 的低分屏，320x320 以上的屏幕 PPI 极高，在全息棱镜折射下不会有颗粒感（锯齿），UI 的发光霓虹效果会异常细腻，非常适合极客桌面摆件。但请注意，驱动高分屏需要 ESP32-S3 使用 QSPI 甚至 RGB 并口（会占用较多引脚）。
*   **交互方式 (无按键/无触摸极客方案)**:
    *   **语音输入 (Primary)**: 乐鑫 `esp-sr` 唤醒 + 语音命令识别（比如“打开设置”、“调亮屏幕”）。
    *   **陀螺仪/六轴传感器 (Secondary)**: **LSM6DS3 / BMI270 (功耗更低、内置硬件算法)**。
    *   **防误触/优雅交互逻辑设计 (Sensor Fusion)**:
        *   **卡尔曼滤波与姿态融合 (Kalman Filter)**: 不直接使用原始角速度，而是通过算法解算出绝对姿态（Roll/Pitch），设置死区（Deadzone），过滤掉桌面震动或轻微触碰带来的噪声。
        *   **"意图确认" 机制 (ALS Intent Lock)**: 这是一个极具创意的简易意图锁方案！无需增加电容触摸极板，而是**直接复用光线传感器 (ALS, 如 BH1750)**。当用户希望操作设备时，只需**用手掌遮挡住光线传感器**（此时光强 Lux 瞬间跌落至极低阈值），系统才会解锁并开始读取卡尔曼滤波解算出的陀螺仪姿态数据（如左翻右翻）。手一移开，光强恢复，系统立刻锁定陀螺仪，杜绝一切桌面震动带来的误触。
        *   **手势映射**: 遮住 ALS 时，向左翻转 = 菜单向左滚动 / 降低音量；向右翻转 = 菜单向右滚动 / 提高音量；设备快速下压（点头） = 确认 (Enter)；设备快速上抬（抬头） = 返回 (Esc)。
        *   **翻转亮屏**: 结合加速度计检测 Z 轴重力变化，实现拿起或翻转设备时自动点亮背光（类似 Apple Watch）。

### 4.3 音频系统 (Audio - 麦克风与扬声器)
*   **麦克风 (录音)**: **INMP441 (I2S 数字麦克风)**
    *   **理由**: 乐鑫 `esp-sr` 语音唤醒强烈推荐使用 I2S 麦克风，INMP441 体积小、底噪低，非常适合桌面距离的唤醒。
*   **音频功放 (外放)**: **MAX98357A (I2S DAC) + 1W/3W 小喇叭**
    *   **理由**: 纯数字 I2S 输入，无需 ESP32 内部 DAC，音质干净，适合做 AI 语音回复和播放“音乐波形图”的背景音。

### 4.4 传感器与电源管理 (Sensor & Power)
*   **六轴姿态传感器 (IMU)**: **BMI270 或 LSM6DS3** (I2C 接口，内置计步和手势识别算法，大大减轻 ESP32 负担，用于翻转、敲击等交互)。
*   **光线传感器 (ALS)**: **BH1750 或 VEML7700** (可选，I2C 接口)。
    *   **理由**: 作为一款桌面时钟摆件，在夜晚关灯后屏幕如果太亮会非常刺眼（尤其是高分屏）。光线传感器可以自动感知环境亮度，并将数据推送给 DataCenter，你的 UI 层就可以自动调低背光或切换为“夜间暗色模式”。
*   **温湿度传感器**: **AHT20 或 SHTC3** (可选，I2C 接口，用于室内环境监测)。
*   **电源管理**:
    *   **锂电池**: 推荐 3.7V 500mAh~1000mAh 聚合物锂电池。
    *   **充放电管理芯片**: **TP4056** (1A 线性充电) + **ME6211** (低压差 3.3V LDO)。
    *   **USB 接口**: Type-C 接口（用于供电和下载）。

### 4.5 引脚分配建议 (Pinout Draft)
*   **SPI (屏幕)**: MOSI, SCLK, CS, DC, RST, BLK (背光 PWM)。
*   **I2S (麦克风)**: SCK, WS, SD。
*   **I2S (扬声器)**: BCLK, LRC, DIN。
*   **I2C (传感器)**: SDA, SCL。
*   **输入**: Encoder_A, Encoder_B, Encoder_Btn。
