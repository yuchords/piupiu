## 关键参数
1. USB速率：对于一般设备USB2.0足够。 对于U盘、外接硬盘推荐USB3.0
2. DP信号：1.4才能满足2k144hz输出。HDMI无法满足该性能，只能选择DP，**要着重看看能不能满足DP1.4的需求**




## 参考风险与成本控制：

1. TVS是非常重要的
2. 铝合金外壳控制在两面打孔总共10个孔的情况下，根据尺寸大小成本在30-50以内（参考嘉立创铝合金外壳加工外壳）


## 设计目标
1. USB下行短路保护的实现
2. 电源管理，当系统外部电源输入5v2a的时候，系统如何运行（应该保证基本功能运行，5v2a是最常见的输入）（注意看HUB芯片PD功能的信号线，当PD协议没有握手成功的时候一般会有信号线，以此信号线去做电路设计）
3. DP能否满足DP1.4规格2k144hz输出
4. HUB芯片的编程接口与信号接口如何处理
5. 另外两块PCB如何接入到此基板，我测量我手头的拓展坞长度是在嘉立创免费打样范围内的。但是要考虑两个PCB如何与此块PCB堆叠？要不要把三棱镜放到基板上？
6. 如何处理电脑输入的usb电源 与 pd电源 与 usb下行输出电源？
