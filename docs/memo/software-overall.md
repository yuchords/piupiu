

# PIUPIU 软件功能需求说明

## 首要说明

系统由两个ESP32共同组成一个嵌入式系统，两者通过UART/SPI通信，主机为系统主控，辅机专注AI形象呈现。

### 主机 ESP32
负责管理整个嵌入式系统，承载主要输入输出外设（麦克风、扬声器、摄像头），整个系统的语音控制、应用逻辑、网络连接均由此运行。
- 显示：3.5寸屏幕，用于复杂内容显示

### 辅机 ESP32
- 显示：1.4寸屏幕，专用于AI虚拟形象显示与情绪反馈

## 基础功能

### OTA功能
- 支持主机与辅机固件的独立网络升级，两者可同步或分别推送
- OTA过程中主机显示进度条，辅机进入"睡眠"动画以防止误操作
- 支持回滚机制，升级失败时自动恢复上一版本

### AI功能
- 语音唤醒词："yo piupiu"，通过用户录制的个人音色模型进行识别（提升唤醒精准度，减少误触）
- 语音识别及AI语义处理通过云端API完成，结果回传本地
- AI可执行系统操作指令（设置闹钟、播放音乐、查询天气等）
- Skills系统：用户可从Skills商店下载第三方技能包，存储于TF卡，本地调用
- Skills商店（见"开放平台"部分）支持第三方开发者上架

### 网络功能
- WiFi：连接网络，支持2.4GHz / 5GHz
- 蓝牙：同时连接电脑（HID键盘模拟、文件传输）和手机（App控制）
- 蓝牙连接设备管理：可命名、排序、快速切换

## 应用功能

### 番茄钟
- 标准25/5分钟模式，支持自定义时长
- 专注期间AI形象进入"专注陪伴"状态（安静但存在感）
- 专注结束后AI形象庆祝动画，鼓励反馈
- 每日/每周专注时长统计，可同步至App
- 支持白噪音/环境音播放（雨声、咖啡厅等），可扩展为Skills

### 计划提醒
- 支持添加定时任务，主机显示清单，到时语音+振动提醒
- AI可通过语音指令快速添加/修改计划（"提醒我明天10点开会"）
- 支持重复任务（工作日、每周、自定义频率）
- App端可远程管理计划清单，双端同步

### 健康
- 久坐提醒：可自定义提醒间隔（30/45/60分钟），AI形象同步做"起身"动作
- 饮水提醒：可设定目标杯数，每次提醒时辅机显示"喝水"动画
- 眼部休息提醒（20-20-20法则）
- 健康数据统计（专注时长、休息次数）同步App

### 日历
- 主机显示月/周/日三种视图
- 连接Google日历 / 系统日历（通过App授权同步）
- 重要日程AI提前语音提醒
- 辅机在有日程当天显示"今天有事"的特殊形象状态

### 歌曲管理
- 支持播放TF卡本地音频文件（MP3/FLAC）
- 蓝牙音频推送：将音频流推送至已配对耳机/音箱
- AI语音控制播放（"播放下一首"、"暂停"、"调小音量"）
- 歌单管理：创建、删除、排序
- 支持第三方音乐平台授权播放（作为Skills扩展，如网易云/Spotify）

### 屏幕健康（待定）
- 检测环境光强度，自动调节屏幕亮度
- 夜间模式：设定时间后自动降低亮度与色温
- 使用时长统计

## AI形象系统（核心竞争力）

### 形象设计规格
- 辅机1.4寸屏幕采用像素艺术风格或Live2D简化版虚拟形象
- 形象初始款3~5种，可通过App选择；后续通过Skills商店扩展付费形象
- 形象具备多套情绪状态动画（参见"特殊状态处理"部分）

### 情绪状态矩阵

| 触发事件 | 辅机动画 | 主机显示 |
|---|---|---|
| 待机（无事件） | 正常呼吸/眨眼循环 | 主菜单（天气+时间） |
| 语音唤醒中 | 耳朵/触角竖起，聆听状态 | 语音输入UI，实时转写文字 |
| AI思考中 | 眼睛转动，思考泡泡 | "正在思考…"动效 |
| AI回复中 | 嘴巴随语音律动，口型同步 | 回复文字流式显示 |
| 番茄钟进行中 | 专注表情，头上显示倒计时小标签 | 番茄钟UI |
| 计划提醒触发 | 挥手/跳跃提醒动画 | 提醒详情弹窗 |
| USB插入 | 闪烁，好奇表情 | 插入提示，显示充电状态 |
| 报警事件 | 红色警告闪烁，惊慌表情 | 详细报警信息 |
| 长时间未交互 | 打盹/睡眠动画 | 息屏或极简时钟 |
| 天气恶劣（雨/雪） | 撑伞/缩成团等应景动作 | 天气详情 |

### 成长系统（差异化功能）
- AI形象具备"好感度"机制，每日使用、完成专注、主动交互可积累好感值
- 好感度达到阶段解锁新动画表情、新互动语音、新外观配件（帽子/眼镜/背景等）
- AI形象具有"记忆"：记录用户习惯（常用功能、习惯起床时间等），形成个性化回应
- 心情系统：根据当天用户完成目标情况，AI呈现不同心情状态（开心、担心、疲惫等）

## 开放平台（Skills生态）

### 第三方Skills开发规范
- 开放SDK，支持开发者开发本地Skills（存储于TF卡）或云端Skills
- Skills可包含：新语音指令、新AI功能、新辅机动画包、新App页面
- Skills通过审核后上架官方Skills商店（App内）

### Skills商店
- 分类：效率工具、生活助手、娱乐、教育、形象包
- 付费/免费混合，开发者分成
- 用户评分与评论系统
- Skills版本管理，OTA推送更新

### 官方内置Skills示例
- 每日新闻简报（晨间语音播报）
- 冥想引导（配合辅机呼吸动画）
- 单词学习（闪卡模式，主机显示，辅机配合表情反馈）
- 股票/加密货币快报

## 交互流程

### 初次激活
1. 主机上电，显示激活向导：产品介绍 → 激活提示 → 激活二维码展示
2. 辅机同步显示欢迎动画（形象从睡眠中被唤醒的动效）
3. 用户扫描二维码，通过App/微信小程序完成激活

### App注册激活流程
1. 用户完成账号注册 → App引导设备配网（WPS或手动输入）→ 设备完成联网，主机显示"联网成功"
2. 用户在App选择AI虚拟形象，选择后主机发送信号至辅机，辅机展示选定形象的登场动画
3. 用户完成其他功能初次设置（时区、通知权限、健康提醒偏好）
4. 主机进入唤醒词音色录入界面，引导用户说三遍"yo piupiu"，生成个人音色模型
5. 录入完成，辅机播放欢迎动画，主机显示欢迎界面，进入主系统

### 特殊状态处理
1. 待机：主机显示主菜单，辅机显示AI形象待机循环动画
2. 语音交互：主机显示实时转写文字与对话UI，辅机进入聆听→思考→回复状态切换
3. USB插入：主机提示插入并显示充电信息，辅机闪烁
4. USB报警（电压异常/过流/短路）：主机显示详细报警信息与处理建议，辅机红色报警闪烁
5. 重要日程提醒：主机弹出提醒，辅机播放提醒动画
6. 长时间无交互（可配置，默认15分钟）：主机息屏，辅机进入打盹动画
7. （可扩展）其他Skills触发的特殊状态

### 主菜单
- 显示：当前时间、日期、天气（温度+天气图标+体感）
- 快捷入口：番茄钟、今日计划、音乐播放器
- 通知角标：未读提醒数量
- 主菜单可通过左右滑动切换至快捷应用卡片视图

### 设置页面
- WiFi管理：扫描/连接/删除网络
- 蓝牙设备管理：已配对设备列表、新设备配对、设备重命名
- AI形象管理：切换当前形象、进入Skills商店
- 好感度与成长记录查看
- 唤醒词重新录入
- 账号与设备信息
- OTA手动检查更新

## 创新功能提案（我的构思）

### 「情绪镜」功能
摄像头实时分析用户表情（疲惫/专注/分心），AI形象同步呈现对应情绪反馈，并在适当时机给出建议（"你看起来有点累，要不要休息一下？"）。这让辅机从被动显示变为主动感知。

### 「仪式感」晨间/晚间模式
用户设定起床时间，主机自动切换晨间模式：播报天气 + 今日计划 + AI形象做"早安伸懒腰"动作。晚间模式：复盘今日专注数据 + AI形象做"晚安"动作 + 自动降低屏幕亮度。强化桌面助手的情感陪伴属性。

### 「专注护卫」防干扰模式
番茄钟进行中，蓝牙设备的通知震动静音，辅机屏幕变暗（仅显示倒计时），主机可选择显示"专注中，勿扰"。休息时才恢复正常。

### 「Skills市集」实体化
TF卡插槽作为"实体Skills"载体——用户可购买预装特定Skills的TF卡（类似游戏卡带概念），插入即激活，形成独特的收藏玩法与线下销售渠道。
